能力边界

视频输出 MP4 或 WebM，也可提取 WAV / M4A 音频；默认重新编码，最长边 1920 像素，可调整尺寸与质量。无法识别的编码会停止。

音频输出 WAV、M4A 或 MP3；MP3 需要全量解码，电脑限 10 分钟 / 80 MB，触屏设备限 2 分钟 / 32 MB，试处理同样受限。长音频优先使用流式 M4A / WAV 或桌面软件。

图片输出 JPG、PNG 或 WebP；保留透明背景请选择 PNG / WebP。动画图只取首帧，不用于动图转换。

串行处理能降低峰值，但不保证大文件不会卡顿；手机端请优先处理短素材。DVD / 光盘、受保护媒体、Office / PDF 格式转换不在本页处理。PDF 可使用网站现有工具。取消时，浏览器原生解码阶段可能要等待结束；文件夹中可能残留空文件或未完成文件，请勿作为成品使用。
